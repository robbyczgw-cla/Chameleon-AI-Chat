Get Running in 3 Minutes

Quick and easy setup

# 1. Clone and install git clone https://github.com/robbyczgw-cla/Chameleon-AI-Chat.git cd Chameleon-AI-Chat npm install # 2. Set up environment cp .env.example .env.local # Add your OpenRouter API key (get one at openrouter.ai) # 3. Run npm run dev # Open http://localhost:3000

Required

OpenRouter API key (free tier available)
Supabase account (free tier works)

Optional

Web search: Serper, Tavily, or Exa API
Voice: OpenAI Whisper + TTS
